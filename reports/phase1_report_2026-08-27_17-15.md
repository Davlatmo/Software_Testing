- Revert or reintroduce numeric-finiteness checks and the math import: add back 'import math' near the top of techshop_testing/Server.py (the diff removed '-import math'). In the minPrice/maxPrice parsing branches, validate with math.isfinite(value) or with 'if math.isnan(value) or math.isinf(value): raise ValueError' (ideally use math.isfinite for clarity). Example (in get_products):

  - try:
      value = float(min_price_raw)
      if not math.isfinite(value):
          raise ValueError
    except ValueError:
      return jsonify({"error": "minPrice must be a number"}), 400
  Do the same for maxPrice.
- Enforce strict category validation: remove the special-case acceptance of 'all'. Replace the block
  if category:
      category = category.lower()
      if category != "all" and category not in VALID_CATEGORIES:
          return jsonify({"error": "Invalid category"}), 400
with

      category = category.lower()
      if category not in VALID_CATEGORIES:

Also verify the single-product endpoint GET /api/products/<id> returns 404 with {"error": "Product not found"} when missing. If those behaviors are not present, add/adjust code accordingly.
